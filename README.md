# Mythic Tower Defense

**🚧 Status: Proiect în dezvoltare**

Mythic Tower Defense este un joc de tip *Tower Defense*, realizat în Unity, în cadrul unui proiect de echipă.

Jocul este construit în jurul unei hărți cu tematică fantasy, împărțită în patru regiuni corespunzătoare anotimpurilor: primăvară, vară, toamnă și iarnă, având în centru un castel.

Scopul jocului este apărarea castelului împotriva valurilor de inamici, prin amplasarea și utilizarea unor turnuri defensive.

## 🎮 Deschiderea proiectului

1. Descărcați sau clonați repository-ul de pe GitHub.
2. Deschideți proiectul folosind **Unity Hub**.
3. Folosiți versiunea **Unity 6.6 (6000.6.8f1)**.
4. În Unity, accesați scena principală:

   `Assets/editor/v1_octogon.unity`

5. Deschideți scena `v1_octogon` prin dublu-click.

**Important:** La prima deschidere, Unity poate încărca o altă scenă. Pentru a vizualiza versiunea actuală a hărții, trebuie deschisă manual scena menționată mai sus.

## 🛠️ Elemente ale proiectului

În prezent, proiectul include:

- Hartă împărțită în patru regiuni tematice.
- Castel central și ziduri defensive.
- Zone destinate amplasării turnurilor.
- Elemente de decor și drumuri.
- Animații pentru distrugerea zidurilor.

Mecanicile de joc, animațiile și celelalte funcționalități sunt în curs de implementare și îmbunătățire.
